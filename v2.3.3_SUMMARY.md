## 🎯 How to Use

### 1. Run App

```bash
streamlit run vpn_admin_pro_multiserver.py
```

### 2. Try Any Operation

Example: Gia hạn user

```
1. Vào 👥 Quản Lý User
2. Click ⏱️ ở user bất kỳ
3. Nhập 30 days → Submit
```

### 3. Check Debug Expanders

**Sẽ thấy 2 expanders:**

```
🔍 Debug - Gia hạn
  ↓ Click to open
  → Shows: Old expiry, New expiry, Diff days

🔍 Debug Response
  ↓ Click to open
  → Shows: Status code, Response text
```

### 4. Diagnose

**If Success:**
```
Status: 200
Response: {"success":true}
✅ Đã gia hạn!
```

→ DONE! Works perfectly!

**If Fail:**
```
Status: 200
Response: {"success":false,"msg":"update error"}
❌ API trả về: update error
```

→ Screenshot debug info + report exact error!
