MAIN WORKFLOW
=============
1. Customer submits registration form
2. POST /register → Validates data
3. Creates customer account in database
4. Auto-selects available x-ui/3x-ui panel
5. Creates VPN client via panel API
6. Stores config in database
7. Returns connection URL to customer
8. Customer can use VPN immediately!
